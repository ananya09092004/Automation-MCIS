NEXUS DEVELOPMENT RULES

1. Architecture is frozen.

2. One platform at a time.

3. No new feature until current platform is complete.

4. Every module must have:
   - Interface
   - Implementation
   - Tests
   - Documentation

5. Every action must be verified.

6. Sensitive actions require user confirmation.

7. Generic engine first, app-specific logic later.

8. No duplicated code.

9. No module should directly depend on another platform.

10. Platform is marked complete only after passing all tests.
